# CIFAR-10 四组对照实验

四组使用同一批 10,000 张测试图像，均训练 8 轮。准确率为预测正确数除以样本数；表中“验证峰值轮”是首次取得最高验证准确率的轮次。

| 组别 | 正确数 | 测试准确率 | 验证峰值 | 验证峰值轮 |
|---|---:|---:|---:|---:|
| baseline | 7779 | 77.79% | 78.16% | 8 |
| augment | 7934 | 79.34% | 79.94% | 8 |
| attention | 7803 | 78.03% | 78.64% | 8 |
| both | 7895 | 78.95% | 79.84% | 8 |

## 两个因素各起了多大作用？

固定注意力为关，加入增强后准确率变化 **+1.55** 个百分点；固定注意力为开，相应变化为 **+0.92** 个百分点。
固定增强为关，加入注意力后变化 **+0.24** 个百分点；固定增强为开，相应变化为 **-0.39** 个百分点。
将另一因素的两种设置等权平均，增强和注意力的平均效应分别为 +1.235 和 -0.075 个百分点。交互项（两种增强设置下注意力增益之差）为 -0.63 个百分点；它描述本次四组实测的非加性，单次训练无法估计不同随机种子的波动。

对测试图像按真实类别分层，在各层内有放回地抽样 2,000 次，每次四组模型共享抽中的样本。95% 配对百分位区间（百分点）：增强平均效应 [+0.61, +1.83]；注意力平均效应 [-0.49, +0.34]；交互项 [-1.48, +0.20]。这些区间仅描述固定模型在同类测试样本重抽样时的波动，不涵盖更换训练种子产生的差异。

## 同一张图上发生了什么变化？

- baseline → attention：加入注意力后纠正 570 张，新增错分 546 张。
- augment → both：加入注意力后纠正 377 张，新增错分 416 张。

从基线到组合组，775 张原本错分的图像被纠正，另有 659 张由正确变为错误，两者之差对应 +1.16 个百分点。另有 1446 张图像两组都分错，包括预测成不同错误类别的情形。paired_examples.png 从纠正和退化两组中分别按固定种子最多抽取四张。
各类中，变化最大的是蛙（81.10% → 87.40%），最小的是鸟（68.50% → 64.50%）。完整十类结果见 class_accuracy.csv。

观察从基线到组合组的定向混淆计数，可以定位净准确率变化来自哪些错误类型：
- 减少最多：猫→鸟（74 → 39 张）、蛙→鹿（43 → 10 张）、狗→鸟（46 → 21 张）。
- 增加最多：狗→猫（134 → 171 张）、鹿→蛙（24 → 55 张）、猫→蛙（42 → 73 张）。

## 各组最常见的定向错误

- baseline：猫 → 狗，158 张，占真实猫样本的 15.80%。
- augment：猫 → 狗，152 张，占真实猫样本的 15.20%。
- attention：狗 → 猫，149 张，占真实狗样本的 14.90%。
- both：狗 → 猫，171 张，占真实狗样本的 17.10%。

误分类图 errors_*.png 按真实类别分别抽样，每类最多一张，编号对应官方测试集顺序。图中分数为模型对预测类别给出的置信度。通过这些个例可以观察混淆对象；它们不能单独说明某种背景或部位导致了误判。

## 复核入口

- learning_curves.png：各组训练和验证的损失、准确率。
- confusion_matrices.png / confusion_*.csv：行是真实类别、列是预测类别；图中文字为样本数，颜色按真实类别归一化。
- class_accuracy.png / class_accuracy.csv：逐类正确数、样本数和准确率；summary.csv：总准确率。
- paired_predictions.csv：逐图四组预测类别、预测分数；pairwise.csv：所有组对的纠正与退化。
- factorial_effects.csv：总体及各类的条件效应、平均效应和交互项，单位为百分点。
- directed_errors.csv：所有定向混淆数及其占真实类别的比例。
