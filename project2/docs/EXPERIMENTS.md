# 实验设计、统计口径与评分点覆盖

## 复现与正确性

完整命令：`python3 -m lab2 experiments --repeats 21 --warmups 3 --seed 20261023`。
给定测试输入来自根目录PDF第3—15页，JSON保存在`data/`。每题执行显式断言；题四Minimax与Alpha-beta在H=2、4分别验证。所有自设输入及种子落盘到`results/generated/`，原始算法与优化版本的值必须一致。并列最优首步允许不同名称，但用独立全窗口根动作值验证其确实最优。

测试通过 `python3 -m unittest discover -s tests -v` 运行。参考网格算法是独立O(V²) Dijkstra，参考博弈算法为独立穷举；没有用被测A*给自己作唯一正确性判据。测试涵盖随机零权/正权/障碍图、随机树、随机有向博弈距离、所有36个课例距离、不可达、同起终点、负收益、不同玩家与非零累计分数、真实缓存命中、可采纳不一致启发引发reopen，以及命令行输入输出。

## 性能实验设计

| 实验组 | 控制变量与比较 | 目的 |
|---|---|---|
| 题一 | 相同地图和邻居顺序；h=0、原始曼哈顿、goal-aware；FIFO/larger-g | 区分启发函数和同分规则的作用 |
| 题二 | 相同进入代价；h=0、原始曼哈顿、goal-aware | 检验E=0与可采纳性，保存逐步代价 |
| 题三 | 同一树；Minimax/Alpha-beta；左到右/右到左 | 解释值回传、剪枝位置和访问顺序 |
| 题四 | 相同6×6矩阵；H=1/2/3/4；两算法×三顺序×缓存开关 | H=2/4为必做；H=1/3补充深度分析 |
| 网格拓展 | 25×25；open/walls/weighted/zero_cost共7图；每图12查询 | 比较Dijkstra、goal-aware、同分规则及ALT |
| 连续查询批次 | 三类图；固定120查询前Q个，Q=1/12/60/120 | 包含每批预处理，直接测量摊销收益而非仅外推 |
| 博弈规模拓展 | 4/6/8宝藏；8宝藏三个种子；六种配置 | 分离排序、剪枝、缓存的贡献和成本 |

权重/障碍随机生成后固定外边界可达；仅从同一连通分量采样路径查询。自设宝藏地图为11×11，各特殊格进入代价1，和题四规则一致。所有负即时收益仍可选。输入生成和选点不纳入核心求解计时，明确属于实验设置。

ALT地标选取规则在运行前确定：最接近四角的可达格，重复点去重。没有按查询结果挑选有利地标。12查询组第一个起终点为对角角点，因此目标恰好是地标，另11个随机查询均保留；连续批次组则全部随机采样，不特选地标终点。

## 时间计量

- 使用 `time.perf_counter_ns()`，单位为纳秒；机器、时钟分辨率、Python版本、种子、预热/重复次数和源文件哈希见`manifest.json`。
- 各组预热3轮，随后21轮计时，每轮随机交错配置，降低固定执行顺序造成的热身/调度偏差。随机序列由固定种子决定。
- 原始`wall_ns`围绕求解入口计时，包含输入校验、返回结果构造，以及ALT每目标启发工厂。文件I/O、结果序列化和绘图不计入。关闭trace，但计数器始终开启。
- 同时保存`algorithm_elapsed_ns`：A*内层包括校验、启发准备、搜索和路径还原；博弈内层仅包括递归搜索。不能把两类算法的内层时间当成相同计时边界。
- **题三注意**：入口 `_validate_tree` 需要遍历整个输入树，外层wall包含它，但搜索`visited`不包含它。因此外层时间可能无法反映纯剪枝算法的全部节省；两个时间字段都保留。
- 表中时间用中位数，保存P25/P75（含端点线性插值）和最小值。IQR是运行分布，不是置信区间。纳秒存储不表示纳秒测量精度。
- 单次查询ALT的索引已建立，预处理另记；`landmark_amortization.csv`按同一trial在线时间求和加一次索引费用，属于组成项核算。`reuse_batches.csv`则直接测量连续批次、每批重建索引，是真实含预处理墙钟时间。
- 缓存指博弈置换表，每次solve都是空表；CPU/操作系统缓存不做强制清除。节点下降不必然意味着时间同比下降，字典操作、排序和启发计算都有额外开销。

## 指标字典

| 字段 | 精确定义 |
|---|---|
| `popped` | A*有效出堆次数，包含终点；不含过期项 |
| `expanded`（A*） | 真正枚举邻居的次数，不含终点；重开后再展开会再次计数 |
| `generated` | 合法邻居被考虑的总次数，包含重复；不是唯一节点数 |
| `discovered` | 曾发现过的不同坐标数，含起点 |
| `reopened` | 已关闭节点因更小g重新进入开放状态的次数 |
| `stale_pops` | 被弹出后丢弃的过期堆项数 |
| `max_frontier` | 堆项峰值，包含尚未清除的过期项；不是字节内存 |
| `preparation_ns` | A*内层elapsed的子集，不能再次相加 |
| `visited` | 博弈递归调用次数，包含终局及缓存命中 |
| `expanded`（博弈） | 实际展开子动作的内部节点次数 |
| `leaves` | 实际执行终局/截断评价的次数；缓存直接返回不增加 |
| `cutoffs` | 因alpha≥beta而确实跳过未访问兄弟的次数；最后一个子节点越界不算 |
| `pruned_branches` | 直接跳过的兄弟分支数，不声称等于全部后代节点数 |
| `cache_hits` | 找到已存状态条目的次数（可能用于返回或缩窄窗口） |
| `cache_stores` | 写入/更新条目的次数，不等于不同缓存状态数 |
| `avoided_visits_vs_minimax` | 相同场景/深度下，基础Minimax访问数减当前配置访问数 |
| `visit_reduction_fraction` | `1−当前visited/基础Minimax visited`；缓存开启时是综合节省，不能只归因剪枝 |
| `table_entries` | ALT正反向距离标量的存储总数，不是内存字节数 |

不同种类节点计数不混用。比如题一默认A*为14次有效出堆、13次展开；题三Minimax为15次递归访问、7次内部展开、8次叶评价。图表轴标签标明所用指标。
